# Page editing rules
Use templates/page.html for every new content page, keeping its shared CSS, deferred assets/site-banners.js loader, and data-site-promotions placeholder. Every content page must show all three banners and shared internal page links below its introduction. Update partials/site-banners.html for shared links/text and assets/site-banners.css for styles. Add new page URLs to the shared navigation and sitemap.xml. Preserve calculator formulas, analytics and verification files unless the user requests changes. Do not modify the external Base44 apps or MakeForToday as part of changes to this repository.
